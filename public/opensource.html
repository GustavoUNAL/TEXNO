Qué es TEXNO

Motor de análisis musical orientado a productores, DJs e investigadores que necesitan entender la arquitectura de un track sin abrir un DAW.

ADN estructurado

Cada análisis genera un JSON/YAML con forma, BPM, espectro completo, tonalidad estimada, dinámica, ritmo y capas heurísticas.

Lab visual

Gráficas interactivas con Plotly: espectro log, energía, cromagrama, bandas, onsets y explicación musical en español.

API + CLI

Sube audio desde la web, llama POST /api/analyze o usa npm run analyze en terminal para pipelines propios.

Stack

  • Node.js 18+
  • Express
  • DSP heurístico
  • Plotly
  • PM2
  • ES Modules

Cómo colaborar

  1. Clona el repo 
    git clone https://github.com/GustavoUNAL/TEXNO.git
cd TEXNO
npm install
npm run dev
  2. Crea una rama para tu feature o fix 
    git checkout -b feat/mi-mejora
  3. Contribuye — mejoras al analizador, UI, docs, tests o nuevas visualizaciones son bienvenidas
  4. Abre un Pull Request en GitHub con descripción clara del cambio

Áreas abiertas

  • ML / stems — separación de pistas con modelos
  • Armonía — detección de acordes y progresiones
  • Forma — segmentación más precisa por secciones
  • UI — más gráficas, temas, accesibilidad
  • Docs — guías, ejemplos y schema del ADN
